OTOH [current manual](https://htcondor.readthedocs.io/en/latest/man-pages/condor_submit.html#coresize) says that default is no core !

<quote>Should the user’s program abort and produce a core file, coresize specifies the maximum size in bytes of the core file which the user wishes to keep. If coresize is not specified in the command file, this is set to 0 (meaning no core will be generated).
</quote>

```
coresize = 0
```
in the JDL (by inspection of Job.submit for this task) ! As it should be,  given these lines:
